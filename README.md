## 🚀 Projetos em destaque

### 🏭 Sistema de Gestão de Cortes
Sistema para gerenciamento e acompanhamento de cortes e produção em uma oficina de costura, centralizando informações e facilitando o controle das operações do dia a dia.

**Funcionalidades principais**
- Cadastro de clientes internos e externos
- Cadastro e gerenciamento de cortes (quantidade de peças, referência, tecido)
- Acompanhamento do status de produção
- Filtros, consultas, edição e exclusão de registros
- Geração de relatórios em PDF
- Compartilhamento de informações via WhatsApp

**Stack:** PHP • MySQL • Flutter • Dart • HTML • CSS • JavaScript

---

### 💰 Sistema de Gestão Financeira
Sistema para gerenciamento de operações financeiras, com estrutura de **API** para comunicação entre a aplicação e o back-end.

**Funcionalidades principais**
- Cadastro e gerenciamento de usuários/clientes
- Registro e controle de operações financeiras e pagamentos
- Consultas e filtros de movimentações

**Módulos**
- 💳 **Troca de Cheques** — gerenciamento de operações envolvendo cheques
- 📄 **Troca de Contas** — gerenciamento de operações envolvendo contas

**Stack:** Node.js • TypeScript • JavaScript • MySQL • API REST

---

### 🎟️ Sistema de Criação e Gestão de Rifas
Sistema para criação e gerenciamento de rifas, com cadastro de usuários e participação nas rifas disponíveis — do cadastro da rifa até a participação do usuário.

**Funcionalidades principais**
- Criação e gerenciamento de rifas
- Cadastro e gerenciamento de usuários
- Participação de usuários nas rifas
- Integração entre aplicação, API e banco de dados

**Stack:** Node.js • JavaScript • MySQL • API REST
